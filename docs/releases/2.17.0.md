## Highlights

- Refresh dependencies while retaining .NET Standard 2.1 and .NET 6, 7, 8, 9, and 10 package targets. .NET 10 is the latest stable .NET release.
- Include the order book performance improvements committed since 2.16.0: fewer intermediate collections and notifications, cached observable wrappers, cheaper pair normalization, and more efficient order book reads and updates. BenchmarkDotNet scenarios and recorded measurements are available in `benchmarks/README.md`.
- Update first-party exchange clients: Aster 1.3.0, Binance 2.8.0, Bitfinex 4.5.0, Bitmex 3.5.0, Bitstamp 1.4.0, Coinbase 2.5.0, and Hyperliquid 1.4.0. The shared transport resolves to Websocket.Client 5.5.0.
- Update System.Reactive to 7.0.0 and Microsoft.Extensions.Logging.Abstractions to 10.0.12. Centralize package versions and refresh the test SDK, Visual Studio test runner, and skippable-test support.

## Publishing and validation

- Replace the stored NuGet API key with NuGet Trusted Publishing through GitHub Actions OIDC, following the `strike-client` release workflow.
- Allow manual publication with `gh workflow run dotnet-core.yml --ref master` as well as publication on pushes to `master`.
- Require versioned release notes and verify that both public NuGet packages embed the release commit before creating the GitHub release.
- Build all six library targets, run Debug and Release unit tests and recorded-message integration tests on .NET 8 and .NET 10, and produce packages and symbol packages for both libraries.
- Make multi-pair diff and validity-reload tests wait for completion signals instead of fixed delays, and run Debug framework targets sequentially to reduce contention on CI runners.
- Keep live exchange tests outside the release gate; the recorded-message integration test requires no credentials or external exchange access.

## Compatibility

No intentional public API removals. Bybit, Luno, and VALR adapters remain enabled. Existing framework targets are retained for compatibility; .NET 6 and .NET 7 are out of support upstream. Consumers should review the dependency version changes, including the System.Reactive major-version update.
